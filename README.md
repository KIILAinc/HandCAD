# handcad

`#f6f6f6` の背景に `#98b1c6` の細いグリッドを表示し、手書きの円・長方形・線分を整形する小さなCAD試作です。1グリッドを10 mmとして扱います。

## PCでプレビュー

このフォルダでローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

円・長方形は一筆で閉じて描くと、自動で整形されます。直線は線分として認識されます。線分や長方形の辺をダブルクリックすると長さをmmで指定できます。上部中央のボタン、または `⌘Z` / `⌘⇧Z`（Windowsでは `Ctrl+Z` / `Ctrl+Shift+Z`）で操作を戻す・やり直すことができます。
